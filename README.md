# SaaS Analytics Platform

This workspace contains the initial scaffolding for a multi-tenant SaaS analytics platform using:

- React + JavaScript frontend
- Java Spring Boot 3 backend

The project is intentionally initialized with package/configuration files only. No application logic has been added yet.

## Structure

- frontend/ — React application scaffold
- backend/ — Spring Boot application scaffold

## Next Steps

1. Install frontend dependencies from the frontend directory.
2. Install backend dependencies from the backend directory.
3. Add the application code, REST controllers, security configuration, and React pages after the scaffold is ready.
