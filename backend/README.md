# SaaS Analytics Platform Backend

This folder contains the initial Spring Boot project scaffold for the backend.

## Included configuration

- Maven `pom.xml` with core dependencies for web, security, JPA, validation, Kafka, Redis, PostgreSQL, JWT, Actuator, and Prometheus
- Spring Boot application entry point
- `application.properties` with environment defaults for local development
- Standard Spring Boot source/resource layout

## Notes

This project is initialized with configuration only and does not include:

- REST controllers
- Security configuration
- Entity models
- Repositories
- Kafka listeners
- Tenant resolution logic
- Business logic or sample features

You can continue by adding the application code once the project structure is ready.
